Lower the cost of taking the next step.

OpenAI offers a 50% batch discount against standard synchronous token rates for supported models. Kaiiron handles submission, polling, and returning the result to your agent.

The tradeoff is time: a batch has a 24-hour completion window and can expire. Each dependent agent turn may require another batch. Total workflow savings depend on usage and routing. OpenAI’s batch terms ↗

Put flexible time to use

Route work that can wait through batch. Use direct when speed matters, or auto to make the choice within your per-call cost allowances.

Keep inference recoverable

Stored batch requests and results give longer workflows a recovery point for inference. Reissue the same identified request or retrieve a detached job by ID.

Three modes. One proxy.
ModeWhen to use itWhat happens
batchThe task can waitSubmit inference to the Batch API and persist the result.
directYou need the response nowForward the request to the provider’s synchronous endpoint.
autoYou want a cost-based choiceGo direct within your per-call cost and premium limits; uncertain estimates favor batch.

Auto uses configured prices and estimates, not a hard workflow budget. Inference recovery does not restore an agent process or its tool state. Read the recovery contract.

BEFORE YOU START

A few practical answers.

Does this use my ChatGPT subscription?

Kaiiron sends requests using your OpenAI Platform API key. Batch inference is API usage billed by the provider; setup does not use a ChatGPT subscription login.

Can I close my agent and come back later?

Detached inference jobs can continue after their submitting client disconnects. The proxy persists their request and result. A full coding session still needs its own checkpoints and continuation logic. Stock Codex does not automatically resend an interrupted inference just because you run codex resume. See restart behavior.

Where do requests and credentials go?

Kaiiron runs on your machine and forwards inference to your configured provider. Batch request bodies and results are stored locally in SQLite. API keys are passed through and are never persisted by Kaiiron; a credential fingerprint isolates stored jobs. After a restart, resuming work requires matching credentials.

Does Kaiiron change the model to save money?

No. Batch changes how inference is submitted. Auto mode selects a route using your price policy without downgrading the selected model or changing its reasoning settings. Savings depend on model eligibility, actual usage, and how much work runs through batch.

What does Kaiiron cost?

Kaiiron is open source under the MIT license. Run it yourself and pay your inference provider directly. There is no Kaiiron hosted service or subscription in this release.
